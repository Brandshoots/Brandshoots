1. Executive Overview & Design System CH 01

BRANDSHOOTS is an ultra-premium creative branding and cinematic production studio based in Hyderabad, India. The studio architects end-to-end commercial brand films, 9:16 vertical video assets, social velocity campaigns, and high-production digital experiences for forward-thinking enterprises.

Unlike conventional agency or corporate SaaS websites, the BrandShoots website operates as a continuous cinematic film. The user does not simply consume static web pages; they journey through an evolving obsidian studio universe where real video assets, 3D geometry, interactive cameras, and editorial typography react in real time.

1.3 Kinetic Scroll Architecture (Lenis + GSAP)

Scrolling across the site is governed by Lenis Inertial Smoothing directly synchronized with GSAP ScrollTrigger ticker loop. This ensures that every 3D camera pan, rotation scrub, and text reveal moves with mathematical physical inertia (duration 1.2s, exponential ease), eliminating scroll judder and creating an effortless cinematic flow.

User Input (Wheel / Touch) → Lenis Normalizer → ScrollTrigger.update() → Three.js Scrub → ACESFilmic Render
